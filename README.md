AfriHack Hackathon Project.
This project was developed during the AfriHack Hackathon Connect, where participants collaborated to design innovative technology solutions.
Our team worked together to conceptualize and build an online academic monitoring platform that helps students, parents, and teachers track 
academic progress and set yearly goals.This project demonstrates collaboration, front-end development skills, and the ability to build solutions 
under time constraints.

Project Objectives
	•	Provide a centralized platform for monitoring learner academic progress
	•	Allow teachers to manage and review student information
	•	Enable parents to track their child’s academic performance
	•	Allow students to view their academic profile and progress
	•	Improve communication between students, teachers, and parents
  
Features
Authentication
	•	Login system for students, teachers, and parents
	•	Access control depending on the user role
	•	Restriction screen for parents with outstanding fees
Student Features
	•	Student Dashboard
	•	Student Profile Page
	•	Academic progress monitoring
	•	Student tools and resources
	•	Support services
Teacher Features
	•	Teacher Dashboard
	•	Teacher Profile
	•	Ability to monitor student performance
	•	Teacher notifications system (client-server model in progress)
Parent Features
	•	Parent Dashboard
	•	Parent Profile
	•	Parent tools
	•	Parent notification system (client-server model in progress)
	•	Ability to track student academic progress

Technologies Used
	•	HTML
	•	CSS
	•	JavaScript

The platform consists of the following modules:
	•	Login System
